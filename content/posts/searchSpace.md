# Introduction

Machine learning aims to find a function $ f^*: x \rightarrow y $, where $x \in \mathcal{X}, y \in \mathcal{Y}$. We don't know what that function is, but we can start with a hypothesis. 

This hypothesis basically allows us to set a space of functions. 

For example, $f(x; \theta_1, \theta_2) = x\theta_1 + \theta_2$ defines the space of linear functions in two dimensions. 

Then, the form of your hypothesis sets a space of possible functions you can get. For example, you better have a linear dependency in your data to work with this space.

# Search Spaces

Therefore, the next question arises, how can we *navigate* through this space to find the best fit for our problem?. 

That question brings us to the concept of optimization. Particularly in deep learning, gradient descent is the efficient way to navigate in the program space generated by deep learning models [^1]. 



## Inductive Bias

Suppose we know that a certain pattern is presented in the relationship between $x$ and $y$; adding this information to our model will be useful.

With that, we can *narrow* our space and be more data efficient. 

That is why different layers in deep learning models usually are better for centering tasks and reducing the number of parameters—convolution neural networks for spatial data, recurrent neural networks for sequential data, and so on. 



# Conclusions

The models set a possible space of function where we can navigate to find the best fit for our problem. 

This navigation is done in deep learning through gradient descent and cost function.

 To be data efficient, we can narrow the search space by adding inductive biases to our model.
